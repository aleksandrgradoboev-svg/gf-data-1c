# Объектная модель `СхемаЗапроса` — что реально доступно

Снято живой пробой на платформе **8.3.27.2130** (база `ut11`) 27.08.2026, а не по справке:
справка перечисляет свойства, но молчит о том, что у половины объектов они не отвечают,
и что текст выражения достаётся приведением к строке.

## Главное правило: текст выражения даёт `Строка()`, а не свойство

У `ВыражениеСхемыЗапроса` **нет ни одного читаемого свойства** — ни `Выражение`, ни
`Псевдоним`, ни `Тип`, и `Представление()` тоже отказывает. Но `Строка(объект)` возвращает
готовый текст выражения:

| Что | `Строка()` даёт |
|---|---|
| поле из `ВыбираемыеПоля` | `Тов.Номенклатура`, `СУММА(Тов.Количество)` |
| условие из `Отбор` | `Тов.Ссылка.Дата МЕЖДУ &Начало И &Конец` |
| элемент `Группировка` | `Тов.Номенклатура` |
| `Соединения[].Условие` | `Ост.Номенклатура = Влож.Ном` |
| `Параметры[].Выражение` (вирт. таблица) | `&НаДату`, `Номенклатура В (ВЫБРАТЬ …)` |

Исключение: `ВыражениеПорядкаСхемыЗапроса` — `Строка()` даёт **имя типа**, не текст.

## Уровни

```
СхемаЗапроса
└─ ПакетЗапросов[]                     Количество() — число запросов пакета
   ├─ ЗапросВыбораСхемыЗапроса
   │  ├─ ТаблицаДляПомещения : Строка  имя ВТ при ПОМЕСТИТЬ, иначе ""
   │  ├─ Колонки[]                     ← ЗДЕСЬ живут псевдонимы результата
   │  │  ├─ .Псевдоним : Строка
   │  │  └─ .Поля[]                    выражения колонки, текст через Строка()
   │  ├─ Порядок[]
   │  │  ├─ .Направление               НаправлениеПорядкаСхемыЗапроса
   │  │  └─ .Элемент → КолонкаСхемыЗапроса   ← текст берётся отсюда, не из выражения
   │  ├─ ВыраженияИтогов[], КонтрольныеТочкиИтогов[], ОбщиеИтоги : Булево
   │  ├─ Автопорядок, ВыбиратьРазрешенные : Булево
   │  └─ Операторы[]                   несколько = ОБЪЕДИНИТЬ
   │     └─ ОператорВыбратьСхемыЗапроса
   │        ├─ ВыбираемыеПоля[]         текст через Строка(); ПСЕВДОНИМА НЕТ
   │        ├─ Отбор[]                 текст через Строка()
   │        ├─ Группировка[]           текст через Строка()
   │        ├─ ВыбиратьРазличные : Булево
   │        ├─ ТипОбъединения          ТипОбъединенияСхемыЗапроса
   │        ├─ КоличествоПолучаемыхЗаписей   Неопределено, если ПЕРВЫЕ не задано
   │        └─ Источники[]
   │           ├─ .Источник → ТаблицаСхемыЗапроса | ВложенныйЗапросСхемыЗапроса
   │           │   ТаблицаСхемыЗапроса:
   │           │     .ИмяТаблицы  Справочник.Номенклатура
   │           │                  РегистрНакопления.ТоварыНаСкладах.Остатки
   │           │                  ВТНоменклатура ← ВТ выглядит обычной таблицей
   │           │     .Псевдоним
   │           │     .ДоступныеПоля[]  состав полей источника
   │           │     .Параметры[]      параметры вирт. таблицы, .Выражение → текст
   │           │   ВложенныйЗапросСхемыЗапроса:
   │           │     .Псевдоним
   │           │     .Запрос → ЗапросВыбораСхемыЗапроса   ← РЕКУРСИЯ
   │           │              .ПолучитьТекстЗапроса() работает
   │           └─ .Соединения[]
   │              ├─ .Условие          выражение, текст через Строка()
   │              ├─ .ТипСоединения    ТипСоединенияСхемыЗапроса
   │              └─ .Источник
   └─ ЗапросУничтоженияТаблицыСхемыЗапроса     ← УНИЧТОЖИТЬ ВТ
      └─ .ИмяТаблицы                   свойств запроса выбора у него НЕТ
```

## Параметры запроса

`Схема.НайтиПараметры()` → коллекция; у элемента читается `.Имя`. Свойство `.Тип` **не отвечает**.

## Ловушки, на которых легко ошибиться

1. **Тип элемента пакета проверять обязательно.** `УНИЧТОЖИТЬ` даёт другой тип, у которого
   падает обращение к `Операторы`, `Колонки` и всему остальному.
2. **Псевдоним поля живёт у колонки, а не у поля.** `ВыбираемыеПоля` псевдонимов не знает;
   связка «псевдоним → выражение» собирается через `Колонки[].Псевдоним` + `.Поля[]`.
3. **Временная таблица неотличима от обычной** по типу источника — только по имени,
   которое совпадает с чьим-то `ТаблицаДляПомещения` выше по пакету.
4. **Несколько операторов = ОБЪЕДИНИТЬ**, а не несколько запросов.
