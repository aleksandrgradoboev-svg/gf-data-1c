# Наш код из старого репозитория — материал, не заготовка

Четыре файла, написанные нами с нуля поверх донорского продукта (коммиты 22.08.2026):
`registry.go` (реестр баз, мультибаза), `bases.go` (управление реестром), `probe.go`
(диагностика канала, различение видов отказа), `query_helpers.go` (сборка и валидация запросов).
Итого 1066 строк. Права на них наши без оговорок.

**Статус: справочный материал, а не код для копирования.** Файлы писались внутри чужой
архитектуры и обращаются к её типам и функциям — дословный перенос притащил бы чужие
интерфейсы в новый продукт и обнулил смысл чистой комнаты. Брать отсюда следует **решения**
(как устроен реестр, какие виды отказа различаются, что проверяется в запросе), а не строки.

Требования, извлечённые из них, уже записаны в `docs/TOOLS.md` и `docs/SPEC.md`.

> Файлы лежат с расширением `.go.txt` намеренно: они справочный материал и не должны
> попадать в сборку продукта.
